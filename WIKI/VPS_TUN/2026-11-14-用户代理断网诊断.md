## 后续正确操作

请从宿主 shell 使用以下明确的控制器入口：

```bash
# 查看状态
sudo /usr/local/sbin/xq-user-proxyctl status

# 开启或恢复 xuqian 全部宿主会话的用户级代理
sudo /usr/local/sbin/xq-user-proxyctl on

# 完整关闭用户级代理并清理它管理的规则，回到原网络
sudo /usr/local/sbin/xq-user-proxyctl off
```

`service xq-user-proxy stop` / `systemctl stop xq-user-proxy` 只停核心，按当前设计保留防直连规则，不能作为正常关闭用户代理的入口。服务的 `Restart=on-failure` 不会自动撤销明确的 stop 操作。重启主机后此用户级代理默认 OFF。

独立命名空间服务 `xq-tun.service` 与用户级服务 `xq-user-proxy.service` 是两个功能；本次恢复只操作后者。
